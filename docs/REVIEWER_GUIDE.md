## 6. AI 실행 기록 화면이 무엇인가

2026-11-14 17:19(KST)에 실제 Claude(`claude-opus-5-5`)로 계약 판단안을 **한 번** 만든 실행의 기록을 재생하는 화면이다. **지금은 AI 를 호출하지 않는다.**
AI 가 받은 입력(조회 도구 5개의 반환값), 만든 출력(권고 대안 B · 문장), 숫자 출처 검증, 이어진 승인요청까지 보인다. 그 실행은 승인요청 생성(권한자 회신 대기)에서 끝났고 로컬 환경에서 실행했다.
운영 화면의 [판단안 만들기]는 **모의 문장**이다(헤더 `AI: 모의`). 숫자 · 권한자 · 권고 등급 · 상태 변경은 어느 쪽이든 규칙 코드가 정한다.

## 8. 로컬 실행

필요: Node.js 22.12 이상. 저장소 루트(원본 폴더 `01_참가자_배포용/` 이 `app/` 옆에 있어야 한다)에서:

```bash
cd app
npm install
npm run dev        # http://localhost:3000
npm run check      # typecheck + lint + test (2026-11-15: 301 통과 · 4 건너뜀)
```

- 환경변수 없이 뜬다: DB 주소가 없으면 메모리 저장소(재시작하면 초기화), AI 키가 없으면 모의 모드. 원본 CSV 는 `../01_참가자_배포용/04_원본데이터` 에서 읽기 전용으로 읽는다.
- Postgres 로 띄우려면 `docker compose up -d`(포트 5433) → `app/.env.local` 에 `DATABASE_URL` → `npm run db:setup`. 빌드본(`npm run build && npm start`)은 DB 가 있어야 화면과 API 가 상태를 공유한다.
- 상세: [TECH_STACK 5-1](TECH_STACK.md#5-1-로컬-개발-db-와-환경변수-2026-11-14). 이 절의 명령은 문서 · `package.json` 기준이며, 기획이 2026-11-15 에 직접 다시 돌려 본 것은 `npm run check` 뿐이다.
