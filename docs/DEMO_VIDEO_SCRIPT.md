# 시연 영상 촬영 대본 (W02)

> 초안 2026-11-15 · 기획. 바탕: [DEMO_SCENARIOS 0-6 시연 진행표](DEMO_SCENARIOS.md#0-6-시연-진행표-한-장-2026-11-14). 촬영과 제출은 사용자가 직접 한다.
> **[운영 공지 확인 필요]** 영상 길이 제한 · 파일 형식 · 해상도 · 음성 필수 여부 · 편집(구간 이어 붙이기) 허용 여부 · 제출 방법. 길이를 몰라 3분 · 5분 · 10분 세 구성안을 만들었다.
> **구간 시간은 모두 추정이다.** 사람이 말하며 진행한 실측이 없다. 촬영 전에 한 번 리허설해 고친다.

## 0. 공통

**표기**
- **[프리셋]** `/scenarios` 에서 해당 지점의 [초기화 후 이 지점까지 재생] → [확인]. 그 지점까지 서버가 같은 결과로 재생한다(건너뛰는 구간).
- **① 카드 6개(①-1 ~ ①-6)는 하나의 시연을 시간순으로 나눈 중간 지점이다(위 → 아래).** 처음부터 직접 조작하려면 ①-1 에서 시작한다. 프리셋 이름의 번호(①-1 ~ ①-6)는 2026-11-15 에 붙였고 **커밋 `d560d6f` 의 배포부터** 화면에 보인다(그 배포는 성공했고 화면 반영을 확인했다). 그 전의 배포판에는 번호 없이 「① 기한 도래 후 (S1-7, 7/18 00:00)」처럼 나온다 — 괄호 안 `S1-n` 으로 같은 지점을 찾는다.
- **번호 주의**: 이 문서의 「①-3」 같은 「 」 안 이름은 **프리셋 카드 이름**이다. 진행표 0-6 의 단계 번호(①-1 ~ ①-7)와는 다른 번호 체계라, 진행표 단계는 "진행표 ①-5"처럼 앞에 "진행표"를 붙여 적었다.
- **[직접]** 화면에서 직접 조작하는 구간. "실제로 돌아간다"의 증거는 이 구간이다 — 어느 구성안이든 직접 구간을 하나 이상 넣는다.
- **[확인]** 누르지 않고 화면만 가리키는 구간.
- 완료 조건(문제지): **C1** 실제로 돌아가는 시스템 · **C2** 세 가지 상황 · **C3** 나만의 확장 · **C4** 다른 부서 영향 · **C5** 원본과 가정 구분.
- 심사 관점(`A01.html` 7절): **J1** 기업 운영의 이해와 기획 · **J2** 데이터에 근거한 판단 · **J3** 작동하는 운영 시스템 · **J4** 변경과 예외에 대한 대응.

**촬영 전 준비**
1. 주소 https://aoura-os-oiw3.axhub.app . **혼자 조작한다**(서버 상태가 하나라 다른 사람이 접속해 조작하면 섞인다).
2. 브라우저 창 1440 폭 권장(타임라인 라벨을 1440 · 1024 폭에서 확인했다 — 프론트엔드 보고). 확대 100%, 북마크바 · 다른 탭 · 알림은 숨긴다.
3. 헤더 확인: `W02` · `AI: 모의` · 「운영 상태 저장소 PostgreSQL」.
4. `/assessments/recorded` 를 한 번 열어 「현재 규칙 계산과 일치」인지 본다. 불일치 경고가 있으면 촬영하지 말고 알린다.
5. 한 번 열어 두어 첫 응답 지연을 없앤다(유휴 뒤 첫 응답 시간은 재지 않았다 — 미확인).
6. `GET /api/meta` 또는 헤더로 지금 상태를 확인한다(다른 브라우저 · 다른 사람이 조작했을 수 있다 — 2026-11-15 확인 도중 다른 브라우저의 조작으로 409 가 한 번 났다). 시작 프리셋을 재생하고 역할을 첫 구간의 역할로 맞춘다. **촬영하는 동안 다른 브라우저 · 탭에서 이 주소를 조작하지 않는다.**
7. **끝나면 「①-6 기한 도래 후 (S1-7)」 프리셋을 재생해 심사자 첫 화면으로 되돌린다.**

**촬영 중**
- 페이지 이동 중앙값 1.4 ~ 1.7초, 쓰기 0.13 ~ 0.4초, 프리셋 재생 0.4 ~ 0.8초(재배포판 실측, 2026-11-15). 버튼을 누르고 **화면이 바뀔 때까지 기다린 뒤 말한다. 두 번 누르지 않는다.**
- 프리셋 재생 1회는 이동 + [재생] + [확인] + 다음 화면 이동으로 **약 8 ~ 10초(추정)**. 편집이 허용되면 구간별로 나눠 찍고 프리셋 재생 장면은 잘라 낸다(잘라 낼 때는 자막으로 "프리셋 재생"을 밝힌다).
- 상태가 꼬이면 그 구간의 프리셋을 다시 재생하고 그 구간부터 다시 찍는다.
- ④ 에서 [선택 건 판단안 만들기]는 반려 **뒤에만** 누른다(먼저 누르면 판 번호가 하나씩 밀린다).

**말하지 않는 것**
- "AI 가 지금 판단합니다" · "모든 판단안을 AI 가 썼습니다" — 배포판의 판단안 문장은 모의다.
- "28억을 절감했습니다" 같은 금액 효과 — 측정하지 않았다. 표본 성과는 "비중 · 순위 · 방향"까지만 말한다.
- 모의 회신을 실제 승인 · 실제 발송처럼 말하지 않는다("모의 회신입니다"라고 말한다).
